# Camp Connor Website
*Mockup of a New Website Design for Camp Connor*

In my COS320 course (Client-Side Web Design & Development) we had to choose a "Computing for Good" community improvement piece. I designed a multi-page web application to help make Camp Connor's platform ADA Compliant. Their current website uses a variety of colors that don’t have enough contrast with each other, making it difficult to read important information. Additionally, there is redundant information and its organized in a way that makes it difficult to find important information quickly. Lastly, the page and none of its components are responsive to screen size changes.

## Soultion
1. Readability (Color Contrast)
2. Easy access/organization to the most important information
3. Flexbox Responsive Pattern

## Target Audience
The target audience is parents and guardians of children attending or wanting to attend Camp Connor. This audience wants transparency about camp logistics, such as, dates, prices, registration and daily schedules. Most of the users will be using their phones so making the application accessible on a mobile device eliminates the barrier some users may face in a non-responsive website.

## Hierarchy
There will be a homepage, an about page, an activities page, a registration page, and a contact page. All pages will be accessible from the navigation bar located at the top of each page. There will not be any subpages for this website.
